# Lab 2.1 – Lösung: Zwei Werkzeuge, eine Aufgabe

Die Ergebnisse sind typische, gekürzte Muster; jedes Werkzeug formuliert anders. Vor Kursbeginn mit den eingesetzten Werkzeugen nachstellen (Stand: 31.10.2026).

## Aufgabe 1: Prompt

```text
Kürze die folgende Antwort an einen Kunden auf höchstens fünf Sätze und
formuliere sie freundlich und klar. Behalte alle Fakten bei.

Sehr geehrte Damen und Herren, bezugnehmend auf Ihre E-Mail vom gestrigen Tage
teilen wir Ihnen hiermit mit, dass eine Verschiebung des Workshops grundsätzlich
[…] keine Einwände bestehen und sich der Ablauf nicht ändert. Mit freundlichen Grüßen
```

## Aufgabe 2: Zwei Ergebnisse

| Werkzeug A | Werkzeug B |
| ---------- | ---------- |
| „Guten Tag, vielen Dank für Ihre Nachricht. Gern verschieben wir den Workshop um eine Woche auf Donnerstag der Folgewoche, zur gleichen Uhrzeit. Auch die zwei zusätzlichen Personen sind herzlich willkommen; am Ablauf ändert sich nichts. Viele Grüße" | „Hallo, eine Verschiebung ist möglich. Der Workshop findet eine Woche später statt. Zwei weitere Personen können teilnehmen. Viele Grüße" |

## Aufgabe 3: Bewertung

| Kriterium | Werkzeug A | Werkzeug B |
| --------- | ---------- | ---------- |
| verständlich | gut | gut |
| vollständig | gut – Termin, Uhrzeit, Personen, Ablauf | mittel – Uhrzeit und „Ablauf unverändert" fehlen |
| Ton | gut – freundlich, verbindlich | mittel – knapp, wirkt kühl |

## Aufgabe 4: Konto

Beispiel: Werkzeug A mit Unternehmenskonto, Werkzeug B privat ohne Anmeldung.

## Aufgabe 5: Spickzettel Abschnitt 3

| Kriterium | Werkzeug A | Werkzeug B |
| --------- | ---------- | ---------- |
| Ergebnis (verständlich, vollständig, Ton) | gut / gut / gut | gut / mittel / mittel |
| Konto (privat / Unternehmen) | Unternehmen | privat |
| Mein Fazit | Werkzeug A für Kundenmails, weil alle Fakten erhalten bleiben und es dienstlich freigegeben ist | – |
