# Glossar

| Begriff | Bedeutung | Modul/Lab |
| ------- | --------- | --------- |
| Agent | eigener Assistent mit festem Zweck, festen Anweisungen und eigenem Wissen | Lab 4.3 |
| Allgemeine KI | hypothetische KI, die jede geistige Aufgabe wie ein Mensch löst; existiert bisher nicht | Lab 1.1 |
| Anonymisieren | Angaben so ändern, dass niemand mehr auf eine bestimmte Person oder Firma schließen kann | Lab 3.1 |
| Anweisungsdatei | dauerhafte Regeln für ein KI-Werkzeug, z. B. benutzerdefinierte Anweisungen oder Projektanweisungen | Lab 4.3 |
| Bias (Verzerrung) | systematische Schieflage in Daten oder Ergebnissen, die Gruppen bevorzugt oder benachteiligt | Lab 3.2 |
| Datenampel | Einteilung geplanter Eingaben in grün (öffentlich), gelb (intern), rot (personenbezogen, vertraulich, fremd) | Lab 3.1 |
| Deepfake | mit KI erzeugtes oder verändertes Bild, Video oder Audio, das echt wirkt | Lab 3.2 |
| DSGVO | Datenschutz-Grundverordnung der EU; regelt die Verarbeitung personenbezogener Daten | Lab 3.1 |
| EU AI Act | Verordnung (EU) 2024/1689, das KI-Gesetz der EU | Lab 3.2 |
| Generative KI | KI, die neue Inhalte erzeugt: Texte, Bilder, Audio, Video, Code | Lab 1.1 |
| Geschäftsgeheimnis | interne Information mit wirtschaftlichem Wert, die bewusst geschützt wird | Lab 3.1 |
| Halluzination | überzeugend klingende, aber erfundene Aussage eines Sprachmodells | Lab 1.2 |
| KI (Künstliche Intelligenz, AI) | Sammelbegriff für Systeme, die Aufgaben lösen, für die bisher menschliche Intelligenz nötig war | Lab 1.1 |
| KI-Kompetenz | Wissen und Fähigkeiten, KI sachkundig, sicher und verantwortungsvoll einzusetzen (Art. 4 EU AI Act) | Lab 3.2, 6.1 |
| Kontext | alles, was dem Modell im Gespräch vorliegt: Prompt, Verlauf, eingefügte Texte, Anweisungen | Lab 1.2, 4.3 |
| Kundendaten Dritter | Informationen, die ein Kunde oder Partner anvertraut hat | Lab 3.1 |
| Lokales Modell | KI-Modell, das auf eigenen Rechnern oder Servern läuft statt beim Anbieter | Lab 5.1 |
| Manipulierte Inhalte | versteckte Anweisungen in Dokumenten oder Webseiten, die eine KI beim Lesen übernimmt | Lab 3.3 |
| Markdown (`.md`) | einfache Textdatei mit Zeichen für Überschriften (`#`) und Listen (`-`) | Lab 4.3 |
| Maschinelles Lernen | das System lernt Regeln aus vielen Beispielen, statt sie programmiert zu bekommen | Lab 1.1 |
| MCP (Model Context Protocol) | offener Standard, über den KI-Werkzeuge auf Dateien, Kalender oder Fachsysteme zugreifen | Lab 5.1 |
| MCP-Client / MCP-Server | Client: das KI-Werkzeug, das Zugänge nutzt; Server: kleines Programm, das einen Zugang bereitstellt | Lab 5.1 |
| Memory | Gedächtnisfunktion: das Werkzeug merkt sich Fakten über die Person aus früheren Gesprächen | Lab 4.3 |
| Neuronales Netz | Rechenmodell aus vielen verknüpften Rechenschritten, Grundlage heutiger KI | Lab 1.1 |
| Offenes Modell | Modell, dessen Dateien heruntergeladen und selbst betrieben werden dürfen | Lab 5.1 |
| Personenbezogene Daten | alle Angaben, mit denen sich eine Person direkt oder indirekt erkennen lässt | Lab 3.1 |
| Prompt | die Eingabe, mit der ein KI-Werkzeug gesteuert wird | Lab 1.2, 4.1 |
| Prüfraster | feste Liste von Prüfpunkten vor jeder Weitergabe eines KI-Ergebnisses | Lab 3.3 |
| Schatten-KI | dienstlich genutzte KI-Werkzeuge ohne Freigabe des Unternehmens | Lab 3.3 |
| Schwache KI | KI für eine bestimmte Aufgabe – alle heutigen Systeme | Lab 1.1 |
| Skill | Ordner mit `SKILL.md` (Name, Beschreibung, Anweisungen), den der Assistent nur bei passender Aufgabe lädt | Lab 4.3 |
| Sprachmodell (LLM) | KI, die aus riesigen Textmengen gelernt hat, wie Sprache aufgebaut ist, und Text erzeugt | Lab 1.2 |
| Token | Textstückchen, etwa ein kurzes Wort oder eine Silbe; das Modell rechnet in Tokens | Lab 1.2 |
| Training / Trainingsdaten | Lernphase vor der Nutzung / die Texte, aus denen das Modell gelernt hat | Lab 1.2 |
| Verbindungsschicht | System zwischen Modellen, Wissen, Programmen und Berechtigungen, das festlegt, was wohin darf | Lab 5.1 |
| Wissensstand | Zeitpunkt, bis zu dem die Trainingsdaten reichen | Lab 1.2 |
