# Best Practices

| Regel | Grund | Lab |
| ----- | ----- | --- |
| Im Beruf zuerst das freigegebene Werkzeug mit Unternehmenskonto nutzen | Nur dort gelten die vertraglichen Datenschutzzusagen des Arbeitgebers | 2.1 |
| Vor jeder Eingabe die Datenampel prüfen | Eine Eingabe ist eine Weitergabe an einen Anbieter und lässt sich nicht zurückholen | 3.1 |
| Personenbezogene Daten anonymisieren oder weglassen | Rollen statt Namen reichen für fast jede Formulierungsaufgabe | 3.1 |
| Jedes Ergebnis vor der Weitergabe prüfen | Ein Sprachmodell liefert die wahrscheinlichste, nicht die richtige Antwort | 1.2, 3.3 |
| Zahlen, Fristen und Quellen einzeln gegen das Original abgleichen | Genau dort entstehen erfundene Angaben am häufigsten | 3.3 |
| Entscheidungen über Menschen nie der KI überlassen | Bias und Hochrisiko-Regeln des EU AI Act | 3.2 |
| KI-Inhalte kennzeichnen, wenn sie für echt gehalten werden könnten | Transparenz schützt Vertrauen – bei Bildern und Stimmen besonders | 3.2 |
| Prompts mit Rolle, Kontext, Aufgabe und Format schreiben | Was im Prompt fehlt, entscheidet das Modell selbst | 4.1 |
| Gezielt nachbessern statt neu anfangen | Der Verlauf ist bereits Kontext | 4.2 |
| Gute Prompts als Vorlage oder `.md`-Anweisung aufheben | Kontext einmal aufschreiben spart jede Wiederholung | 4.3 |
| Memory regelmäßig ansehen und aufräumen | Gespeicherte Fakten fließen in jede künftige Antwort ein | 4.3 |
| Verbundenen Assistenten nur nötige Zugriffe geben | Wer mehr verbindet, braucht klarere Berechtigungen | 5.1 |
