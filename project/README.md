# Projektdateien – Nordwind Consulting

Alle Übungen nutzen diese vorbereiteten Dateien. Nordwind Consulting ist fiktiv; Personen, Zahlen und Dokumente sind erfunden. Eigene oder vertrauliche Daten sind in keiner Übung nötig.

| Datei | Inhalt | Verwendet in |
| ----- | ------ | ------------ |
| `nordwind-ausgangslage.md` | Unternehmen, neue KI-Regeln, Ansprechstellen | alle Labs |
| `ki-spickzettel.md` / `ki-spickzettel.docx` | Vorlage mit acht Abschnitten, wächst im Kurs | Lab 1.1–4.3 |
| `beispiel-prompts.md` | kopierbare Prompt-Karten | Lab 1.2, 2.1, 4.1, 4.3 |
| `nordwind-szenarien.md` | sechs Alltagssituationen zur Einordnung | Lab 2.2 |
| `nordwind-kundenmail.md` / `.docx` | Kundenmail, Faktenlage, steifer Antwortentwurf | Lab 2.1, 4.1, 4.2 |
| `datenampel-faelle.md` | zehn geplante Eingaben und ein Fall zum Anonymisieren | Lab 3.1 |
| `ki-antwort-mit-fehlern.md` | KI-Antwort mit drei eingebauten Fehlern und Faktenblatt | Lab 3.3 |
| `nordwind-reisekosten-richtlinie.md` / `.docx` | erfundene Reisekostenrichtlinie (Wissensquelle) | Lab 4.3, 5.1 |
| `skills/nordwind-reisekosten/SKILL.md` | fertiger Skill aus der Drei-Assistenten-Kette | Lab 4.3 |
| `kette-zwischenstaende.md` | Ausgaben der drei Assistenten, Vergleich mit/ohne Skill | Lab 4.3 |
| `beispiel-kontext-baustein.md` | Musterergebnis einer Anweisungsdatei | Lab 4.3 |
| `quiz/runde-1-ki-landkarte.md` | Quiz-Runde 1 | Lab 1.1 |
| `quiz/runde-2-datenampel.md` | Quiz-Runde 2 | Lab 3.1 |
| `quiz/runde-3-fehler-finden.md` | Quiz-Runde 3 | Lab 3.3 |
| `quiz/mcp-fallback-fragen.md` | drei Fragen aus der MCP-Demo | Lab 5.1, 6.1 |
| `quiz/finale.md` | KI-Check mit 17 Fragen (10 live, 7 Selbsttest) | Lab 6.1 |

Die Lösungen der Quiz-Runden stehen in der jeweiligen `-sol.md` des Labs.
