# Datenampel – zehn Eingaben

Grundlage für Quiz-Runde 2 in Lab 3.1. Für jede Eingabe gilt die Frage: Darf diese Information in ein KI-Werkzeug – und wenn ja, in welches?

| Farbe | Bedeutung bei Nordwind |
| ----- | ---------------------- |
| grün | öffentlich – darf in jedes KI-Werkzeug |
| gelb | intern – nur ins freigegebene Werkzeug mit Unternehmenskonto |
| rot | personenbezogen, vertraulich oder fremd – nicht eingeben (außer anonymisiert) |

| # | Geplante Eingabe |
| - | ---------------- |
| 1 | die Pressemitteilung von Nordwind zum neuen Standort, bereits auf der Website veröffentlicht |
| 2 | das interne Projektbudget für die Stadtwerke Nordhafen |
| 3 | eine Bewerbung mit Foto, Lebenslauf und Gehaltsvorstellung |
| 4 | ein Besprechungsprotokoll, in dem alle Namen durch Rollen ersetzt wurden („Projektleitung", „Kunde") |
| 5 | die Krankmeldung eines Kollegen, um eine Vertretungsplanung zu formulieren |
| 6 | ein öffentlich verfügbarer Fachartikel, der zusammengefasst werden soll |
| 7 | die interne Präsentation „Strategie 2027" der Geschäftsführung |
| 8 | eine Kundenmail mit Name, Telefonnummer und Vertragsnummer |
| 9 | die interne Reisekostenrichtlinie |
| 10 | Zugangsdaten zum Kundenportal, damit die KI eine Anleitung schreibt |

## Fall zum Anonymisieren

Original:

```text
Herr Jonas Petersen (Stadtwerke Nordhafen, Tel. 0471 555 0182) beschwert sich,
dass die Lieferung zum Vertrag NH-2026-114 zwei Wochen zu spät kam.
Bitte eine höfliche Antwort formulieren.
```
