# Lab 4.1 – Übung: Die vier Bausteine eines guten Prompts

**Ändert den KI-Spickzettel?** Nein — der vollständige Prompt wird in Lab 4.2 verbessert und dann als Prompt-Vorlage eingetragen.

## Ausgangslage

Das Projektteam der Stadtwerke Nordhafen bittet per Mail um eine Workshop-Verschiebung und zwei zusätzliche Teilnehmende. Die Antwort soll mit einem KI-Chat entstehen.

Bereitgestellt in `output/project/`:

- `nordwind-kundenmail.md` — die eingegangene Mail und die Tabelle „Was Nordwind dazu weiß"
- `beispiel-prompts.md` — Karte 3 mit dem knappen Prompt und der Vorlage für den vollständigen Prompt

## Aufgaben

1. Öffne einen neuen Chat und sende den knappen Prompt aus Karte 3 zusammen mit der Mail. Speichere die Antwort als „Variante A".
2. Fülle die Vorlage aus Karte 3: Ergänze Rolle, Kontext (die Fakten aus „Was Nordwind dazu weiß"), Aufgabe und Format.
3. Öffne einen weiteren neuen Chat und sende den vollständigen Prompt. Speichere die Antwort als „Variante B".
4. Vergleiche beide Varianten anhand der Tabelle unten und trage je Zeile „A", „B" oder „gleich" ein.

| Kriterium | Besser in |
| --------- | --------- |
| beantwortet beide Fragen der Mail | |
| enthält nur Fakten aus der Tabelle (kein erfundener Termin) | |
| Länge und Form passen ohne Umbau | |
| Ton passt zu einem Kunden | |

5. Markiere in Variante A jede Stelle, die das Modell selbst entschieden hat (z. B. ein Datum, eine Länge, eine Anrede).

## Checkpoint

- Zwei Antworten liegen vor: Variante A (knapp) und Variante B (vier Bausteine).
- Der vollständige Prompt enthält alle vier Bausteine sichtbar getrennt.
- Die Vergleichstabelle ist ausgefüllt.

## Abschlusskriterien

- Der vollständige Prompt ist im Wortlaut gespeichert (für Lab 4.2).
- In Variante A sind mindestens zwei vom Modell selbst entschiedene Stellen markiert.

## Erweiterung

Lass im vollständigen Prompt den Kontext-Baustein weg und sende ihn erneut. Prüfe, ob das Modell einen Termin erfindet.

## Fallback

Ohne Zugang zu einem KI-Chat: Bearbeite Aufgabe 2 schriftlich und vergleiche in Aufgabe 4 die Beispielantworten aus der Lösung. Einschränkung: Das eigene Ergebnis wird nicht erzeugt, nur der Unterschied nachvollzogen.
