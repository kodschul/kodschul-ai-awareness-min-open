# AI Awareness – Künstliche Intelligenz verstehen, sicher nutzen und richtig prompten

**½-Tag-Workshop** · Office/Business · Deutsch

</div>

---

Teilnehmerunterlagen des Kurses **„AI Awareness – Künstliche Intelligenz verstehen, sicher nutzen und richtig prompten“**. Alle Übungen spielen bei der fiktiven Beratung **Nordwind Consulting**; Lab für Lab entsteht ein **persönlicher KI-Spickzettel**, den Abschluss bildet ein KI-Kompetenz-Selbsttest mit Bezug zu Art. 4 EU AI Act.

Jedes Lab besteht aus drei Dateien: Theorie (`-thx.md`), Übung (`-exc.md`) und Lösung (`-sol.md`). Alle Pfade in dieser Datei sind relativ zu diesem Ordner.

## Auf einen Blick

| | |
| --- | --- |

| **Zielgruppe** | alle, die KI im Beruf und Alltag sicher nutzen wollen |
| **Vorkenntnisse** | keine; keine technischen oder Programmierkenntnisse |
| **Sprache** | Deutsch |
| **Szenario** | Nordwind Consulting (fiktiv); Ergebnis: persönlicher KI-Spickzettel und erster Kontext-Baustein |
