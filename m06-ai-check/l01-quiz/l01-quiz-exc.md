# Lab 6.1 – Übung: KI-Kompetenz-Selbsttest

**Ändert den KI-Spickzettel?** Nein — das Ergebnis ist eine persönliche Auswertung je Themenbereich.

## Ausgangslage

17 Fragen über alle Module: zehn für das Quiz-Finale, sieben für den Selbsttest. Je Themenbereich gibt es zwei Fragen; die Fragen 8–10 stammen aus der MCP-Demo in Lab 5.1 und prüfen die Nordwind-Richtlinie, nicht einen Themenbereich.

Bereitgestellt in `output/project/`:

- `quiz/finale.md` — alle Fragen ohne Lösungen

## Aufgaben

1. Beantworte die Fragen 1–10 aus `quiz/finale.md` (je Frage eine Antwort: A, B oder C).
2. Beantworte die Fragen 11–17.
3. Vergleiche mit der Lösung und trage die Anzahl richtiger Antworten je Bereich ein:

| Bereich | Fragen | richtig (0–2 bzw. 0–3) |
| ------- | ------ | ------------- |
| Grundlagen | 1, 11 | |
| Werkzeuge | 2, 12 | |
| Datenschutz | 3, 13 | |
| Ethik und Recht | 4, 14 | |
| Prüfen | 5, 15 | |
| Prompten und Kontext | 6, 16 | |
| Ausblick | 7, 17 | |
| Nordwind-Richtlinie (MCP-Demo) | 8, 9, 10 | |

4. Wähle den Bereich mit dem niedrigsten Ergebnis und notiere das Lab, das nachgelesen wird (Tabelle „Die sieben Themenbereiche").

## Checkpoint

- Alle 17 Fragen sind beantwortet.
- Die Tabelle enthält für jeden Bereich einen Wert.

## Abschlusskriterien

- Ein Bereich zum Weiterlernen und das passende Lab sind notiert.
